# Какой прогноз можно получить с доступными данными?

<p class="intro">Подобрать модель почасового спроса для каждого из трёх наборов входов.</p>

| Сценарий | Какие данные известны к моменту расчёта |
|---|---|
| **Календарь** | Дата, местный час и признак праздника |
| **Календарь + основная погода** | Календарь, температура, ветер, видимость и дождь |
| **Календарь + вся погода** | Всё перечисленное, а также влажность, солнечная радиация и снег |

<p class="take">Статус проката задаём отдельно. При закрытии прогноз равен нулю.</p>

# Как выбирали девять победителей

<p class="intro">В каждой паре «схема × сценарий» выбирали конфигурацию с минимальной RMSE на валидации. Затем оценивали победителя на отложенных часах.</p>

| Схема | Обучение и выбор настроек | Финальный тест |
|---|---|---|
| **Временные фолды** | История растёт от фолда к фолду. Валидация в июле–октябре. Победителя обучаем на всех 7 618 часах до теста. | Последние 847 открытых часов |
| **Случайно внутри месяца** | В каждом месяце 80% часов для обучения и 10% для выбора. Сохраняем обученного победителя. | Ещё 10% каждого месяца, всего 845 часов |
| **Случайно по году** | Те же доли 80% и 10% среди всех часов года. Сохраняем обученного победителя. | Ещё 10% года, всего 847 часов |

<!-- RMSE измеряется в арендах за час и сильнее учитывает крупные промахи. Дополнительно считаем MAE, R² и Peak RMSE по верхним 10% фактического спроса в тесте. Временной тест начинается 23 октября в 17:00. Случайные тесты оценивают отложенные часы знакомого года. -->

# От исходного часа до прогноза

<div class="pipeline">

# Как воспроизвести результат

<p class="intro">Из корня репозитория. Нужны uv и Python 3.12.</p>

```bash
# Обучение кандидатов и финальная оценка
uv run --project lshvetsov --locked --python 3.12 -m lshvetsov.validation.train
uv run --project lshvetsov --locked --python 3.12 -m lshvetsov.evaluation.finalize

# HTML-отчёт из сохранённых CSV
uv run --project lshvetsov --locked --python 3.12 -m lshvetsov.docs.reports.report

# Форма прогноза после сохранения моделей
uv run --project lshvetsov --locked --python 3.12 -m streamlit run \
  lshvetsov/streamlit_app/app.py --server.address 127.0.0.1
```

<p class="take">Готовый отчёт лежит в <code>lshvetsov/docs/reports/report.html</code>. Для его сборки достаточно CSV из репозитория.</p>
