# Почасовой прогноз велопроката в Сеуле

Сравниваем три набора входов на [SeoulBikeData.csv](../SeoulBikeData.csv). [План](PLAN.md) описывает цели, границы эксперимента и правила выбора моделей.

## Запуск эксперимента

Из корня репозитория выполните команды через uv. Версии зависимостей закреплены в `uv.lock`.

```bash
uv run --project lshvetsov --locked --python 3.12 -m lshvetsov.train
uv run --project lshvetsov --locked --python 3.12 -m lshvetsov.finalize
uv run --project lshvetsov --locked --python 3.12 -m lshvetsov.report
```

`train` оценивает модели на открытых часах с декабря 2017 по октябрь 2018 года. Результаты сохраняются в трёх таблицах.

- [rolling_cv.csv](results/rolling_cv.csv) — четыре последовательных фолда с июля по октябрь. Сводные метрики рассчитаны по объединённым прогнозам. Также показана RMSE каждого месяца.
- [monthly_80_20.csv](results/monthly_80_20.csv) — первые 80% часов каждого месяца объединяем для обучения, последние 20% идут в проверку. Открытые часы отбираем после разметки.
- [random_80_20.csv](results/random_80_20.csv) — случайное 80/20 на открытых часах с `random_state=42`.

Для каждого набора входов оцениваем линейную регрессию, четыре настройки Ridge, четыре настройки Lasso и по восемь конфигураций двух вариантов бустинга. Первый предсказывает спрос напрямую. Второй предсказывает отклонение от медианы по часу и типу дня, рассчитанной на обучающей части. Эта же медиана служит простым ориентиром. Точка росы исключена из расширенного набора.

`finalize` берёт лучшую конфигурацию каждого семейства в каждом сценарии и на каждой схеме. Совпавшие конфигурации проверяются один раз. Все кандидаты переобучаются на открытых часах по октябрь включительно. Победитель сценария определяется по RMSE на открытых часах ноября. Ноябрьская метрика участвует в выборе модели. Для независимой проверки финалистов нужен следующий период.

- [november_candidates.csv](results/november_candidates.csv) — метрики всех кандидатов на ноябре, указаны исходные схемы отбора и победители.
- [november_family_metrics.csv](results/november_family_metrics.csv) — сравнение всех семейств алгоритмов на одинаковых ноябрьских часах. Для каждой пары сценария и семейства проверены кандидаты от трёх схем и сохранена конфигурация с минимальной RMSE.
- [november_metrics.csv](results/november_metrics.csv) — RMSE, MAE, R² и Peak RMSE трёх победителей и почасовой медианы.
- [november_predictions.csv](results/november_predictions.csv) — факт и прогнозы победителей и медианы на всех часах ноября. Для закрытых часов прогноз равен нулю.

`report` собирает автономный `results/report.html` с целью, результатом по каждому сценарию, методологией, таблицами замеров и графиками. Обученные модели сохраняются в `results/models/` рядом с [манифестом](results/models/manifest.json). HTML и Joblib генерируются локально. Параметр `--output-dir` команды `train` и `--results-dir` двух следующих команд позволяют использовать другой каталог.

## Форма прогноза

После команды `finalize` запустите Streamlit из корня репозитория.

```bash
uv run --project lshvetsov --locked --python 3.12 -m streamlit run lshvetsov/app.py --server.address 127.0.0.1
```

Откройте [локальную форму](http://127.0.0.1:8501). Выберите набор входов, укажите дату и час по Сеулу, праздник и статус проката. Видимость вводится в километрах и переводится в единицы CSV. При закрытии форма скрывает погоду и возвращает 0. Карточка модели показывает ноябрьские RMSE и Peak RMSE, а также схемы, которые выдвинули эту конфигурацию. Ошибка погодных моделей измерена с фактической погодой из CSV.
